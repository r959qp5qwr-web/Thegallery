Your word on four things

  1. Freshness wording on a work. "· confirmed 3 days ago" reads to a visitor like an order or a verification.

    Recommended: "Updated 3 days ago" on its own quiet line. The stale caution after 90 days stays exactly as it is.

  2. The contact disclosure (GAL-C1). The governed sentence, "Payment, delivery, returns and any dispute are arranged with them; The Gallery does not process the transaction", reads like a legal warning at the moment someone messages an artist.

    Recommended: keep it word for word in the contact sheet, where the rule requires it, and use the plain line "You'll be talking to Anika directly. Price, delivery and payment are agreed between you." only on the maker's gallery.

  3. CI token (DOCTRINE_READ_TOKEN). You said "go with your recommendations", which is to set it. Only you can create it: a fine-grained, read-only GitHub token on builders-doctrine (Contents: read), saved as a repository secret on Thegallery. It takes about 5 minutes.

    Reply "token set" when it's done. Until then PRs stay red on that check alone, and each merge message says so.

  4. Live operator account. It is unknown whether the live project has one. It is needed for the suspension walk after Wave 5.

    One word: yes / no / don't know.
