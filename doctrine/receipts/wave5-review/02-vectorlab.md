# 02 — vectorlab UX skills lens (anti-slop, empty-states, typography, spacing, page-patterns, labels, viewports)

**Verdict.** The live site reads as novice because it is one template stamped six times. Every
public route that has nothing to show (entrance, browse/clay, saved, workshops, not-found,
search-none) renders the same 168 px CSS drawing of a beige wall and an empty slab (`EmptyPlinth`
in `src/components/Chrome.tsx`, `.plinth` in `system.css` 214–228), then says it is empty three
times in a row (context line + heading + body), then offers one outlined button that leads to
*another* empty page. A visitor who taps every CTA goes round a loop of identical empty rooms
(Saved → See all work → entrance → For Makers; clay → See textile → empty textile; search-none →
Browse by material → empty clay). On top of that, the chrome repeats itself: "For Makers" appears
three times on the entrance at 390 (CTA, footer, bottom bar), the for-makers page states its name
twice and its first sentence twice before the heading ends, and maker-unknown prints "NOT
AVAILABLE" directly over "This gallery is not available". The type system has the right
ingredients but breaks its own floor: labels at 11.5 px, nav at 10.5 px (9.5 px under 340 px),
display line-height 1.02–1.04, and mono used as a prose face. Alignment drifts between 16, 20 and
28 px left edges on the same screen. None of this is the token palette's fault; it is how the
empty state, the duplicated labels and the button hierarchy were assembled. The governor's
"duplication" is literal and countable, and that is what to fix first.

## Moves (whole-product lifts)

1. **Make the empty state one rule, not one picture.** Type-only empties everywhere: serif subheading, one value sentence, one action that leads somewhere non-empty. Delete the six repeated plinth drawings. This removes the single most visible duplication (V01, V03, V07, V08).
2. **Give the pre-launch entrance its own composed page.** It should announce the opening, say what will hang here and address makers. Hide the material rail and every link into empty materials until the first work is published (V02, V04).
3. **Say each thing once.** Audit every screen for a label that repeats the heading or the chrome: context lines, kickers, the footer "For Makers", the duplicated taglines. Delete the repeat, not the original (V05, V06, V07, V08).
4. **Give the primary action real weight.** One filled ink action per screen, line-style for everything else. This is the one place where the foundation's "never a filled block" rule is costing the product its hierarchy (V09, SYSTEM CHANGE).
5. **Raise the type floor and keep mono to labels only.** Labels and nav at 12 px, display at 1.1 line-height, and no mono on wrapping prose or row metadata. The institution voice then reads as deliberate instead of as fine print (V10, V11, V12; tokens are SYSTEM CHANGE).
